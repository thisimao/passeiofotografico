# Passeio Fotográfico 2026 — Protótipo Polaroid

Projeto atualizado para aproximar a interface do protótipo visual enviado e transformar a área de captura em uma câmera Polaroid digital.

Alterações principais:
- interface clara, com textura de papel e identidade azul/laranja;
- câmera com corpo inspirado em câmeras Polaroid instantâneas;
- visor, flash, botão de disparo e lente decorativa;
- vídeo da câmera integrado ao corpo da câmera;
- resultado apresentado em uma moldura de foto Polaroid;
- moldura gerada em PNG continua seguindo o protótipo original, com Passeio Fotográfico 2026, Aprendizagem, ECOS e Senac;
- layout responsivo para computador e celular.

Para testar, abra pelo VS Code + Live Server ou execute:
python -m http.server 8000

Depois acesse http://localhost:8000

Em produção, use HTTPS para permitir o acesso à câmera.
